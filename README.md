# ปลดหนี้ มีทางออก (Debt Resolution Thailand) 🛡️

เว็บไซต์และเครื่องมือดิจิทัลสำหรับการวางแผนแก้ไขปัญหาหนี้สินอย่างเป็นระบบ เข้าใจง่าย ทันสมัย และเป็นส่วนตัว 100%

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **🩺 แบบประเมินสุขภาพหนี้ (Debt Health Check & DTI Calculator)**
   - คำนวณสัดส่วนภาระหนี้ต่อรายได้ (DTI) พร้อมแสดงเกณฑ์ความเสี่ยง (ปลอดภัย, เริ่มตึงตัว, เสี่ยงสูง, วิกฤต)
   - คำแนะนำเฉพาะบุคคลตามสถานะการค้างชำระ (ปกติ / ค้าง 30-90 วัน / NPL / มีหมายศาล)

2. **🧮 เครื่องมือวางแผนชำระหนี้อัจฉริยะ (Debt Repayment Simulator)**
   - บันทึกและจัดการรายการหนี้ได้จริง (จัดเก็บในเครื่องผ่าน LocalStorage)
   - เปรียบเทียบ 2 กลยุทธ์ปลดหนี้ยอดนิยมระดับสากล:
     - **Snowball (บอลหิมะ):** ปิดหนี้ยอดเล็กก่อน เพื่อสร้างชัยชนะทางจิตวิทยาและโมเมนตัม
     - **Avalanche (หิมะถล่ม):** โปะหนี้ดอกเบี้ยสูงที่สุดก่อน เพื่อประหยัดเงินดอกเบี้ยรวมสูงสุด
   - จำลองการใส่ "เงินโปะพิเศษรายเดือน" และแสดงผลลัพธ์ว่าหมดหนี้เร็วขึ้นกี่ปี ประหยัดดอกเบี้ยได้กี่บาท
   - แสดงกราฟเปรียบเทียบระยะเวลาและการลดยอดหนี้ด้วย Chart.js

3. **🚨 ชุดปฐมพยาบาลหนี้ด่วน 5 ขั้นตอน (Emergency First-Aid Checklist)**
   - เช็กลิสต์อินเตอร์แอคทีฟ 5 สเต็ปเพื่อตั้งสติและอุดรอยรั่วทางการเงิน

4. **🧭 เข็มทิศ 4 ทางออกหลักในการแก้หนี้ (Solutions Directory)**
   - การรวมหนี้ (Debt Consolidation)
   - การปรับโครงสร้างหนี้เชิงรุก (TDR)
   - คลินิกแก้หนี้ by SAM (ดอกเบี้ย 3-5% ผ่อน 10 ปี)
   - ทางด่วนแก้หนี้ ธนาคารแห่งประเทศไทย
   - การไกล่เกลี่ยในชั้นศาล & สิทธิการอายัดเงินเดือน (ห้ามอายัดหากเงินเดือนไม่เกิน 20,000 บาท)
   - การแก้ไขปัญหาหนี้นอกระบบตามกฎหมาย

5. **🗣️ คัมภีร์บทพูดเจรจาเจ้าหนี้ (Negotiation Scripts)**
   - สคริปต์ขอปรับโครงสร้างหนี้ล่วงหน้าก่อนค้างชำระ พร้อมปุ่มคัดลอกข้อความในคลิกเดียว
   - สคริปต์ขอปิดจบหนี้ก้อนเดียว (Hair-cut)
   - สิ่งที่ควรพูด vs ข้อห้ามพูดเด็ดขาด
   - สิทธิลูกหนี้ตาม พ.ร.บ. การทวงถามหนี้ (ห้ามทวงเกินวันละ 1 ครั้ง, ห้ามประจาน)

6. **📞 ศูนย์รวมสายด่วนทางการ (Official Hotlines)**
   - แบงก์ชาติ (ศคง. 1213)
   - คลินิกแก้หนี้ (1443)
   - ศูนย์ดำรงธรรม หนี้นอกระบบ (1567)
   - กรมบังคับคดี (1111 ต่อ 79)
   - ปราบปรามหนี้นอกระบบ (1599)
   - สายด่วนสุขภาพจิต (1323)

7. **🖨️ ระบบพิมพ์ / Export สรุปแผนปลดหนี้ (Print & PDF)**
   - จัดหน้าเฉพาะสำหรับพิมพ์หรือบันทึกเป็น PDF เพื่อนำไปใช้วางแผนหรือใช้เจรจากับสถาบันการเงิน

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: เปิดใช้งานทันทีผ่านเบราว์เซอร์
- ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานใน Google Chrome, Microsoft Edge, หรือ Safari ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริม

### วิธีที่ 2: รันผ่าน Local Web Server
```bash
# ติดตั้ง serve หรือใช้ npx
npm start
# หรือ
npx serve -l 3000 .
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
